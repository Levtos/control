# Architecture Decision Records

ADRs are durable decisions and are updated through reviewed pull requests.
Each ADR links to the GitHub Issue that records the decision and acceptance
criteria.

The current governance decision is [ADR 0002](0002-github-only-governance.md):
GitHub-only source of truth, one Issue agent, explicit handoff, repository
lifecycle states, and a separate technical/live gate. It is tracked in
[Levtos/control#21](https://github.com/Levtos/control/issues/21).

The current shared UX decision is [ADR 0001](0001-ux-frontend-standard.md):
Svelte 5, Vite, TypeScript, typed REST/WebSocket contracts, static bundle, and
thin gateway. The active tracking Issue is
[Levtos/control#17](https://github.com/Levtos/control/issues/17).

The verified stable Core Contracts release is `v0.1.1`. References to
`0.2.0-alpha.1` describe historical planning, not the current stable state.
