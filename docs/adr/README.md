# Architecture Decision Records

ADRs are durable decisions and are updated through reviewed pull requests.
Each ADR links to the GitHub Issue that records the decision and acceptance
criteria.

The current shared UX decision remains Svelte 5, Vite, TypeScript, typed
REST/WebSocket contracts, static bundle, and thin gateway. The historical
GitLab control issue and ADR are provenance only; future changes belong here.

The verified stable Core Contracts release is `v0.1.1`. References to
`0.2.0-alpha.1` describe historical planning, not the current stable state.
