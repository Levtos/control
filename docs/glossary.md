# Glossary

- **Backlog**: identified work not currently being implemented.
- **Testing**: implementation and technical verification are in progress or
  complete; live acceptance remains open.
- **Live**: Benni's final live gate has passed.
- **Tests Pass**: automated tests, review, or technical pilot evidence exists.
- **Live Verified**: behavior was observed on a live Home Assistant instance.
- **Stable release**: normal `vX.Y.Z` release without prerelease marker.
- **HACS visibility**: the released version is visible as an installable or
  available update in HACS.
- **Project Memory**: durable, versioned knowledge under `docs/`.
