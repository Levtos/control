# Project Memory

`control/docs/` is the single canonical Project Memory. It is versioned,
reviewable, searchable with Git and `rg`, and changed through pull requests.

Stable architecture, contracts, ADRs, glossary, integration ownership,
runbooks, and release rules belong here. Current work, decisions and evidence
belong in GitHub Issues. Detailed repository-specific implementation belongs
in the affected repository.

GitHub Pages may later render these files, but generated Pages is only a view.
Do not create a GitHub Wiki or external Wiki as a second editable truth.
