# Media integration overview

Media device truth remains in device masters. Context integrations derive
global meaning. Media Policy decides target audio paths, volume and HomePod
behavior; Media Apply executes those decisions. Plug protection and final
power-cut decisions remain in Plug Policy.

The public repositories are:

- `Levtos/benni_media`
- `Levtos/benni_media_context`
- `Levtos/benni_media_state`
- `Levtos/benni_media_policy`
- `Levtos/benni_media_apply`
- `Levtos/Media_Art_Wrapper`

Current releases and live behavior are time-sensitive. Record exact versions,
SHAs, tests, and HACS evidence on the relevant GitHub Issue rather than
hard-coding snapshots into this overview.
