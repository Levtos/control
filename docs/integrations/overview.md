# Integrations overview

The active public integration set is maintained under the `Levtos` GitHub
account. The GitLab project names are retained only as provenance and archive
references.

| Layer | Active repositories |
|---|---|
| Foundation | `benni-core-devices`, `benni-core-state`, `benni-core-contracts` |
| Context / media | `Title_classifier`, `benni_media_context`, `benni_media_state`, `benni_media` |
| Policy / apply | `benni_blind_policy`, `benni_climate_policy`, `benni_door_policy`, `benni_light_policy`, `benni_media_policy`, `benni_media_apply`, `plug_policy_engine`, `benni_notification_router` |
| Render / utility | `benni_scene_presets`, `ha_wake_planner`, `discord-game`, `stash-ha`, `Media_Art_Wrapper` |

HACS-relevant repositories are public. `einhornzentrale`, `haos_eltern`,
and other active Home Assistant configuration repositories remain private.
Repository-specific contracts and runbooks stay in each repository; this
page records the platform map and ownership boundary only.
